# Scenes, game states and level loading

How HP3 decides what's loaded, and every way each map can be entered. The full machine-readable graph is
[`data/map_entrances.json`](../data/map_entrances.json), generated by `tools/build_scenes.py`.

## Maps vs. game states

- **Maps** (`maps/*.unr`, 34 files) are the levels. Each one holds its own world geometry, lighting and actors.
  Loading another map is the only thing that changes the geometry.
- **Game states** (`GSTATE000` … `GSTATE120`, [`data/game_states.json`](../data/game_states.json)) are story phases.
  They don't load anything. When a map loads, every actor runs `Actor.FilterForCurrentGameState()` (KnowWonder code
  in `Engine.u`):
  - if the actor's `ExcludeFromGameStates` list contains the current state, it's switched off;
  - otherwise, if its `Group` names one or more states (`None,GState040`) and none is current, it's switched off.

  Switched-off actors are hidden and lose collision but stay in memory. The state travels with level changes
  (`?GameState=` on the URL). A map opened directly uses its `LevelInfo.DefaultGameState`.
- What changes by state is almost all story staging. In InsideHub that's hundreds of cutscene keypoints and camera
  positions, students and student spawners, popups, cutscene triggers and player starts. In GroundsHub it also
  includes 20 static meshes. In the challenges, a few exits are excluded in some states.

## How levels change

1. **Level exits placed in the map:** `kwGame.ChangeLevelTrigger` with `NewMapName`, optionally setting `NewGameState`
   (`bSetGameState`). Touch-triggered, or fired by tag.
2. **Cutscene scripts:** `system/Cutscenes/*.int`, plain-text INI files with one `[Sequence_n]` per actor
   (`PawnTag=`) and `line_n=` commands. The level-relevant commands are `ChangeLevel <map>`, `SetGameState <state>`,
   `Trigger <tag>`, `GiveMap`, `SetProp Actor=<tag> <prop>=<value>`, `savegame 0` and `SaveBookMark`.
   A map's `CutSceneTrigger` (with `Event` = the cutscene name) plays them. Some are chained from other cutscenes
   or play on level start.
3. **New game:** `FirstLevel=HP3_Adv1Express.unr` in `Default.ini`/`hppoa.ini`. The front end is `HP_Preamble`.

## Story chains (vanilla)

Maps that can only be reached through the story, in the order the game loads them:

| Chain | Sequence | How it starts |
| --- | --- | --- |
| Opening | **Adv1Express** → **GroundsDada** → Ch1 Carpe Retractum | New game, then `0180ADV1DemExit` (sets `GState000`) |
| Patronus | Quidditch → **Adv2ExpPatronum** → **Adv3Library** → InsideHub | Challenge-chamber cutscenes in `GState065` (set `GState070`), or the Patronus intro at GroundsDada |
| Endgame | **BuckyExecuted** → **Adv5Shack** ⇄ WhompingWillow → DementorBattle → Infirmary → **Adv6Paddock** → DementorBattle → DarkTower → InsideHub | Challenge-chamber cutscenes in `GState075`; states `085` → `090` along the way |
| Exams | **FA1Ron** → **FA2Hermione** → **FA3Harry** → GroundsHub | Ron's exam intro (`CutSceneTrigger13`, InsideHub or GroundsDada) in `GState090`, sets `GState100` |
| End | HP3_Final | GroundsHub `10530EndLastDayYes`, `GState100` |

**Bold** maps contain checks. Quidditch, WhompingWillow, DementorBattle, Infirmary and DarkTower contain none
(Final has one chest).

Hub-reachable maps: the three challenges (side-room and classroom doors, state-limited), COMC, BeanBonus,
DungeonHUB and PortraitPassword_B–F.

## Regenerating

```
python tools/build_scenes.py "<game dir>" data
```

It reads every `system/Cutscenes/*.int`. Cutscenes that change level but aren't fired by a map event are listed under
`unattributed_cutscenes`, with the maps that reference them by name.
